# Contributing Guidelines

Thank you for contributing to this project. To keep everything organised, please follow these simple rules:

1. Create a new branch for every feature or fix.
2. Write clear commit messages that explain what you changed.
3. Open a Pull Request after testing your changes.
4. Keep files and folders well-organised.
5. Mention the related Issue number in your Pull Request.
6. Be respectful and keep feedback constructive.
