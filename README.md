# VCS Comprehensive Project

This repository is used for learning and demonstrating Git and GitHub concepts. The project shows how to work with branches, merge conflicts, pull requests, undo operations, and basic documentation.

---

## 📌 Project Overview
This project covers:
- Creating and managing branches  
- Merging and handling conflicts  
- Using pull requests  
- Reverting and stashing changes  
- Organising a clean repository structure
