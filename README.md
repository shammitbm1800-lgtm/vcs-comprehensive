# VCS Comprehensive Project

This project is a simple Python-based demo used to practice Version Control concepts like branching, merging, conflict resolution, pull requests, and automation. It focuses more on Git workflows than the actual program logic.

---

##  Project Overview
This project demonstrates:
- How to set up a repository
- Creating and working with branches
- Handling merge conflicts
- Using pull requests
- Undo operations (revert + stash)
- Basic documentation and repo organisation
