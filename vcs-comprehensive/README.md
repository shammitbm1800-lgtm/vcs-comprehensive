# VCS Comprehensive Project

This project is a simple Python-based demo used to practice Version Control concepts like branching, merging, conflict resolution, pull requests, and automation. It isn't focused on features but on clean Git workflow and repository structure.

---

##  Project Overview
The goal of this project is to understand how real projects are organized and managed using Git and GitHub.  
It includes:
- Basic project setup  
- Feature branches  
- Merge conflicts and resolutions  
- Pull requests and reviews  
- Undo operations (revert & stash)  
- GitHub actions (coming later)
